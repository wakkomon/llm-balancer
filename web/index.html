Server

Basis-URL des LLM-Servers ohne /v1 – der Pfad der Anfrage wird angehängt.
Kleinere Priorität wird bevorzugt, wenn mehrere Server frei sind.
Wird als „Authorization: Bearer …“ an diesen Server geschickt.

API-Token erstellen

Mindestens 12 Zeichen. Gespeichert wird nur ein Hash.

Token erstellt

Jetzt kopieren – er wird nicht noch einmal angezeigt. In LiteLLM als api_key eintragen.

Gruppe

Anfragen, die ein Server dieser Gruppe bearbeitet, bekommen diesen Modellnamen – die Zuordnung zur Gruppe erfolgt weiter über den angefragten Namen (mit „*“ in den Modellen nimmt die Gruppe jedes Modell an).
Wartet eine Anfrage länger als angegeben, darf auch ein Server der Fallback-Gruppe sie übernehmen. Sind alle Server dieser Gruppe down, sofort. Mit „Modell dort“ wird der Modellname für den Fallback ersetzt.
Ein Server gehört zu höchstens einer Gruppe; wählst du ihn hier, verlässt er seine bisherige.
